# 키워드 적재 소스 v1

자동 소스 셋(`tour`·`kakao`·`popular`)이 **구조적으로 못 닿는 장소**를 운영자가 이름으로
직접 넣는 경로를 추가했다. 카탈로그 커버리지 97.2% → 98.4%.

전제 — [landmark-name-absorption-v1.md](landmark-name-absorption-v1.md) §5 의 "키워드 검색 적재
경로가 있어야 잡힌다" 후속이다.

## 1. 먼저 기존 소스로 되는지부터 확인했다

새로 만들기 전에 `popular`(네이버 추천 글 언급 → 카카오 정규화)를 **서브지역 단위**로 돌려 봤다.
시도 코퍼스가 넓으면 대표 명소가 묻힌다는 기존 주석 때문이다.

`--regions=영주,전주 --sources=popular` 결과 — **`자만벽화마을` 이 들어왔다.**
카카오 `category_group_code` 가 빈 값이라 카테고리 검색으로는 영원히 못 잡던 장소다.
전주 커버리지 78% → 89%. `부석사` 도 장식 없는 정본 행이 생겼다
(그전엔 `부석사 [유네스코 세계유산]` 뿐이었다).

즉 **`popular` 을 서브지역으로 돌리는 것만으로 상당 부분이 해결된다.** 이건 새 코드가 아니라
운영 방법의 문제였다.

### 그래도 남는 구멍

`--regions=서면 --sources=popular` 은 **수집 1건**으로 끝났다. `전리단길` 은 안 들어왔다.
목적지 어간이 코퍼스를 못 만들면(`'서면 여행지 추천'` 같은 검색어가 성립하지 않는다)
이 소스는 통째로 빈다. 그런데 `전리단길` 은 카카오에 `AT4` 로 멀쩡히 있다 —
반경 500m 카테고리 검색이면 나온다([kakao-category-search-ceiling-v1.md](kakao-category-search-ceiling-v1.md) §2).
조밀 적재는 랭킹 때문에 못 켠다. 그래서 **"있는 걸 아는데 어떤 자동 경로도 안 데려온다"** 가 남는다.

## 2. `keyword` 소스

```bash
pnpm ingest:places -- --regions=부산 --sources=keyword --keywords=전리단길,흰여울문화마을
```

이름을 주면 카카오 키워드 검색으로 정본(이름·좌표·주소)을 받아 적재한다.
**사람이 지정했다고 무검증으로 넣지 않는다** — 관문 둘이 그대로 걸린다:

1. **주소 기준 지역 검증** — 카카오는 지역을 붙여도 타지역 동명 장소를 섞어 준다.
   실측: 목적지 제주에 `해운대해수욕장` 을 주면 거부된다. 1위가 타지역이면 **다음 문서로 넘어간다**
   (`사직공원` → 서울 문서를 건너뛰고 광주 문서를 고른다)
2. **적격 게이트** — 다른 소스와 같은 `isEligibleItineraryCandidate`.
   실측: `스타벅스` 를 주면 프랜차이즈 지점 규칙에 걸려 안 들어온다

dedupe 순서에서 **가장 앞**에 둔다 — 사람이 콕 집어 넣은 정본이 같은 장소의 다른 소스 행보다 우선한다.

## 3. 측정 — 커버리지는 올랐고 랭킹은 제자리다

| | 적재 전 | 적재 후 |
| --- | --- | --- |
| 카탈로그 행 | 45,716 | 45,881 |
| 적재 커버리지 | 97.2% | **98.4%** |
| 카탈로그에 있는 정답 | 149건 | **151건** |
| 실제로 찾은 정답 | 83건 | 81건 |
| R@5 | 0.266 | **0.288** |
| R@10 | 0.451 | 0.438 |
| R\|cat | 0.572 | 0.549 |
| MRR | 0.778 | 0.747 |

**정직하게 — 랭킹 지표는 안 올랐다.** 두 가지가 섞여 있다:

- **분모 효과**: `자만벽화마을`·`전리단길` 이 카탈로그에 들어오면서 "카탈로그에 있는 정답"이
  2건 늘었다. 아직 상위 16 에 못 들어오므로 R\|cat 의 분모만 커진다
- **코퍼스 드리프트**: 적재가 없던 부산 광안리에서도 `수영사적공원` 이 빠졌다. 적재와 무관하다.
  (같은 시점 연속 재실행은 **소수점까지 동일**했으므로, 두 측정 사이의 시간 차가 원인이다)

카탈로그 변경이라 한 프로세스 A/B 가 불가능하다 — 이 표는 시점이 다른 두 측정의 비교이고,
그 한계를 안고 읽어야 한다. 확실한 건 **커버리지 +1.2%p 와 구조적 구멍 두 개가 닫혔다**는 것이다.

행은 유지했다. 조밀 적재(4,036행 flood)와 달리 정밀하게 고른 165행이고, 랭킹을 깨지 않았다.

## 4. 남은 것

- **`popular` 서브지역 패스를 정기화할 것.** 이번에 영주·전주·광안리·속초·강릉만 돌렸다.
  코드가 아니라 운영 항목이다
- `소백산` 은 카카오 정본 주소가 **충북**이라 영주(경북) 케이스의 지역 필터에 안 걸린다.
  도 경계에 걸친 산은 `keyword` 로도 못 넣는다 — 지역 검증이 옳게 막는 것이라 규칙을 풀 순 없고,
  경계 장소를 두 시도에 함께 등록하는 별도 설계가 필요하다
- 새로 넣은 두 장소가 **아직 상위 16 에 못 든다.** 적재는 필요조건일 뿐이고 랭킹은 별개다
